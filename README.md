# Bus Fever Cocos MVP

基于 Cocos Creator 3.8.8 的可玩首关工程。项目包含 TypeScript 源码、场景、Android 构建配置，以及运行所需的模型、贴图和动画资源。

## 运行

1. 安装 Cocos Creator 3.8.8，导入仓库根目录。
2. 在资源面板打开 `assets/OwnedArtGameplay.scene`，启动预览。
3. 等乘客进入环道后，按颜色发车。满员车辆会离场，最后一辆车离场后进入胜利结算。

## 构建 Android

在 Creator 构建面板选 Android，启动场景选 `OwnedArtGameplay`，ABI 选 `arm64-v8a`，使用调试签名。仓库根目录的 `android-build.json` 提供这套构建配置。SDK、NDK 和 JDK 使用本机 Creator 配置。

当前版本已在 Android 15 ARM64 模拟器验证并行进站、240 人登车、六车离场、通关奖励、受阻回退、暂停与重开。行车曲线和部分动画时序依据首关录像拟合，仍在逐项对照。

## Android 整关验收

首关使用 240 名独立乘客，每辆车有 40 个座位。回放逐一核对上车记录，并验证并行进站、满位继续登车、四辆受阻车的回退、通关领奖、暂停与重开。乘客按录像估算的间距进场。

在 Android 15 ARM64、1080×2400 的模拟器上安装候选 APK，待设备连接 adb 后执行以下命令。脚本需要 Bash、adb、Python 3、jq、rg、xxd 和 shasum。证据目录会保存截图、录像、运行事件及逐车计数。

```sh
adb -s emulator-5586 install -r "$apk"
bash tools/replay_level_one.sh "$apk" "$evidence" emulator-5586
```

首次进入首关时，原提示卡、手势与高亮指出目标车，点错目标会被拦截。环道使用原 Prefab 的 39 个位置并以四人为组运行，空位经过右上入口时补入下一组。匹配的组经过出口时预留四席，逐人到车后扣减座位。普通阶段及尾段分别控制环速；首辆红车和末辆红车均可复用左侧第一个普通车位。完成首关后的会话内重玩采用自由调度。

首关的两辆蓝车分别挡住同侧的两辆黄车或红车。进入自由重玩后，点击受阻车辆会前移至接触位置再退回，保留原有车位和乘客状态。挡车关系按录像摆位、车头方向与原车身碰撞盒计算。原版录像只覆盖成功发车路线。环道满位时会检查整圈的可登车乘客，并等待正在进行的登车结束。验证失败重开时另用十组蓝色乘客占满环道、前四辆车均为红色或黄色的测试关。

乘客走向当前车位时采用原配置的上车点和每秒 3.8 个场景单位的移动速度。行走距离决定何时到达并扣座。原 VAT 片段继续驱动人物姿态。
